# Owner decisions required before inviting a business

The deployed public identity endpoint returns empty operator/contact fields and `identity_configured:false`. No value has been invented or published in this continuation.

| Area | Exact decision/input needed |
| --- | --- |
| Operator | Approve the exact legal name, Colzo trading name and business structure for public display. Existing knowledge of a person's identity is not consent to publish it. |
| Address | Supply the exact geographic/service address and explicitly approve public display. Do not infer or publish a home address. |
| Support | Confirm whether the already documented `support@getbusiness-ai.com` is owned and monitored; verify message delivery. Supply/approve the support telephone number required by current readiness validation. No test email has been sent. |
| Registration | Supply company/VAT numbers only if applicable; confirm non-applicability otherwise. |
| Data return | Choose the export format, responsible handler, request/authority-verification process and the window/deadline for requesting and receiving an export after the pilot. |
| Retention | Decide the post-pilot retention period and trigger, who executes deletion and by when, handling of backup copies and any required audit/legal retention. Current 365/730-day settings are review intervals, not automatic deletion commitments. |
| Documents | Approve the completed pilot addendum and its relationship with the existing terms, privacy notice and DPA. Confirm the customer-facing processing information reflects the actual providers and approved lifecycle decisions. |

These decisions are separate from technical acceptance. Supplying them does not activate a pilot, accept a DPA on anyone's behalf or authorize invitations. Real-business authority and named-user scope must be established when onboarding is separately approved.
