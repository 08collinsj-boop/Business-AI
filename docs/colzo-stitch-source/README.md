# Colzo Stitch source recovery

This directory preserves the recovered Colzo interactive UI prototype source alongside the app.

## Files
- `colzo-preview.html`: standalone HTML, CSS, SVG and JavaScript prototype recovered from the saved conversation file library on 14 October 2026.

## Important
This is a design/reference prototype, not proof every screen is production-integrated. It includes demonstration content and demo-only actions. Do not treat demo values as live customer data or demo-only actions as production integrations.

Review its screen renderers and interaction handlers against the current application before migrating implementations. Keep authentication, authorization, server-side validation and existing API contracts in the production app. This source was recovered as-is; it does not establish that every Google Stitch export was recovered.
